    Intentional accessibility defects on this page (6)
    1. D-01 Unlabeled field. The full-name input has a placeholder but no label, so it is announced only by its type.
    2. D-02 Vague link. An eligibility link is called “Click here”, which is useless out of context and in a link list.
    3. D-03 Silent validation. Submitting an incomplete first step shows a visual error summary that is not announced and is not focused.
    4. D-04 Unnamed icon button. The remove-attachment button contains only a trash icon with no accessible name.
    5. D-05 Unannounced update. The word counter changes on every keystroke without a live region.
    6. D-06 Lost context after submit. The form is replaced by a receipt while focus stays on the removed button, and nothing is announced.
